# Social templates (UI kit)

Recreations of Magic Look's two live social formats, composed from the design-system components.

- **StoryTemplate.jsx** — 1080×1920 story. Patterned ivory field, inset ivory-deep card (radius 44), signature top-right, headline, ochre rule + dotted features, product cut-out, handle + icons bottom-left. Source: `Products/0001-blue-chair-assets/0001-blue-chair-posters/0001-blue-chair-poster-01.jpg`.
- **PostTemplate.jsx** — 1080×1350 feed post. Full-bleed warm interior, product cut-out, gold calligraphy title, 80px ochre footer bar with handle/icons/phones (left) and address (right). Source: `Products/0001-blue-chair-assets/posters-templates/poster.png`.
- **Editor.jsx** — thin preview shell: format tabs, editable headline/features, export dialog (mock).

The cut-away chair render used in the originals was not provided as a standalone file; the kit uses `blue-chair-view-000.png` instead.
